
# AI Business Report Generator

A Python application that transforms sales CSV data into
business KPIs, visualizations, and AI-assisted management reports.

## Technology Stack

- Python
- FastAPI
- Streamlit
- Pandas
- SQLite
- Groq LLM API

## Features

Planned features:
- CSV upload and validation
- Business KPI calculations
- Period-over-period comparisons
- Notable change detection
- AI-generated management summaries
- Interactive charts
- Downloadable PDF reports
- Report history

## Project Status

Under development.
